# Corpus de exemplo

Os documentos desta pasta sao **ficticios**, escritos para demonstrar o
fatiamento por artigo, a recuperacao e a avaliacao. Eles imitam a linguagem de
uma resolucao normativa brasileira, mas nao reproduzem nenhuma norma real de
nenhuma instituicao.

Para usar com um corpus proprio, aponte `RAG_CORPUS_DIR` para a pasta dos seus
arquivos `.txt` e reescreva `eval/golden.json` com perguntas reais.
